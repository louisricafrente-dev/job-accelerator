# Job Accelerator review - 19 October 2026

Scope: current local checkout, including existing uncommitted changes. No application code was changed. This is a focused review, not an exhaustive branch or deployment audit.

## Findings

1. **High - login has no application-level attempt limit** (`src/server.py:143`). Password OR six-digit TOTP grants admin access. Neither route nor auth helper limits failed attempts. Add a shared attempt counter/cooldown suitable for multiple instances. Deployment-level protections were not inspected.
2. **High - requested search keywords are discarded** (`src/aggregator.py:220`, `:232`). Each category keeps only its first two keywords and absent categories inject defaults. Reproduced: react developer, node.js developer, python developer, qa automation engineer becomes junior software engineer, android developer, react developer, node.js developer. Honor explicit queries; apply defaults only when none are supplied. Current regression verifies request acceptance, not connector execution.
3. **Medium - inaccurate job-board attribution** (`src/connectors/remote_feed.py:163`, `:208`, `:264`). Wellfound reads Remotive; Foundit and Upwork read Jobicy, while assigning their own board names. Upwork additionally prefixes ordinary feed listings with [Contract]. This misrepresents provenance, contract type and independent board coverage. Remove substitute connectors or preserve the actual upstream source and employment type.
4. **Medium - ordinary description text rejects junior jobs** (`src/classifier.py:222`). Reproduced: Junior Android Developer with description 'You will collaborate with senior engineers and report to the engineering manager.' becomes Senior / Lead and is rejected. Prefer title seniority; parse explicit requirements rather than every occurrence of senior/manager. Several connectors also discard available descriptions, losing training and requirements evidence.
5. **Medium - reference date does not control relative-date normalization** (`src/models.py:87`). normalize_date uses the actual UTC clock, but is_within_14_days compares against ref_date. Existing test with ref_date 2026-10-16 and 'today' fails on 2026-10-19. Pass one reference clock through both operations.
6. **Medium - connector failures can appear successful** (`src/connectors/jobspy_adapter.py:61`, `src/aggregator.py:257`). Adapter catches exceptions and returns []; orchestrator labels this active and can finish status ok even when upstream fails. Return an explicit failure outcome and distinguish partial failure from a legitimate zero-result search.
